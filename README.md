# 🐉 Skyrim Build Randomizer

**Deja que los Dioses decidan tu destino.**

Skyrim Build Randomizer es una herramienta interactiva para generar personajes y builds aleatorias inspiradas en *The Elder Scrolls V: Skyrim*.

Crea un personaje único para tu próxima aventura en Tamriel combinando razas, sexos, rasgos y diferentes historias de origen. ¡Cada generación ofrece una nueva forma de jugar!

## ✨ Características

### 🧝 Creación de personaje
- 10 razas jugables de Skyrim.
- Selección aleatoria de personaje masculino o femenino.
- Retratos correspondientes a cada combinación de raza y sexo.
- Posibilidad de volver a generar el personaje individualmente.

### ⚔️ Character Traits
- Más de 100 rasgos disponibles.
- Selección de 3 rasgos aleatorios sin repetir.
- Cada rasgo incluye su nombre original, traducción y descripción.
- Posibilidad de volver a aleatorizar los rasgos.

### 📜 Origin Stories
- 40 historias de origen diferentes.
- Títulos originales y traducciones al español.
- Descripciones que proponen objetivos, motivaciones y aventuras.
- Imágenes asociadas a cada historia.
- Posibilidad de descubrir una nueva historia en cualquier momento.

### 🎲 Generación completa
Con un solo botón puedes generar una build completa que combina:
- Raza y sexo.
- Tres rasgos aleatorios.
- Una historia de origen.

¡Tu próxima aventura nunca será igual!

## 🎮 Cómo utilizarlo

1. Abre Skyrim Build Randomizer.
2. Pulsa **Generar Build Completa**.
3. Descubre el personaje que te ha tocado.
4. Consulta sus tres rasgos y su historia de origen.
5. Si quieres cambiar algún resultado, utiliza los botones individuales de aleatorización.

## 🛠️ Tecnologías

Este proyecto está desarrollado utilizando:

- CSS3
- JavaScript

No necesita instalaciones adicionales ni programas externos para utilizarse desde el navegador.
